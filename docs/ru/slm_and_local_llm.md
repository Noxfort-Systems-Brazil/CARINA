# 🤖 Компактные языковые модели (SLM) и интеграция локальных LLM

Данный документ описывает подсистему компактных языковых моделей (Small Language Models — SLM) системы CARINA, расположенную в каталоге [`src/slm/`](../../src/slm). В нем подробно рассматривается, как CARINA формирует экспертные текстовые заключения из сырых тензоров нейросетевой атрибуции с помощью локальных автономных больших языковых моделей (преимущественно **Qwen3.5 2B** через файл `Qwen3.5-2B-UD-Q6_K_XL.gguf`, с поддержкой резервных моделей **Qwen2.5 1.5B/3B** или **Llama-3.2 3B**) без обращения к внешним облачным API.

## 1. Архитектурная философия: 100% автономная конфиденциальность

В практике муниципального управления передача оперативной телеметрии транспортных систем, журналов инцидентов или параметров работы контроллеров во внешние коммерческие облачные сервисы (OpenAI, Anthropic, Google Cloud) категорически нарушает регламенты информационной безопасности, законодательство о защите персональных данных (152-ФЗ, LGPD/GDPR) и цифровой суверенитет муниципалитета.

CARINA выполняет весь синтез текстовых аналитических заключений **на 100% локально на собственном оборудовании (on-premise)**:
- Работает через оптимизированные привязки C++ (`llama-cpp-python`).
- Поддерживает **квантованные модели GGUF** (например, `Q6_K_XL`, `Q4_K_M`, `Q8_0`).
- Потребляет всего от **~1.5 ГБ до 3.5 ГБ видеопамяти VRAM** (или оперативной памяти CPU с аппаратным ускорением AVX-512).
- Обеспечивает полностью детерминированную генерацию текста за счет «жадного» декодирования с нулевой температурой ($\tau = 0.0$, `repeat_penalty = 1.05`).

## 2. Базовые модули каталога `src/slm/`

### 2.1 Семантический преобразователь (`semantic_transducer.py`)
Расположен в [`src/slm/semantic_transducer.py`](../../src/slm/semantic_transducer.py):
- Служит основным публичным интерфейсом генерации текстовых инженерных объяснений.
- По умолчанию использует модель `Model_Vault/Qwen3.5-2B-UD-Q6_K_XL.gguf` с контекстным окном `n_ctx = 8192`.
- Преобразует численные кортежи телеметрии вида `(queue_length=18, speed=12.4 km/h, veto=True)` в предметно-ориентированные промпты транспортной инженерии.
- Содержит резервный эвристический движок: при отсутствии видеокарты, дефиците памяти или отсутствии файла весов генерирует детерминированный экспертный текст по правилам без сбоев системы.

### 2.2 Локальный транслятор Llama (`local_llama_transducer.py`)
Расположен в [`src/slm/local_llama_transducer.py`](../../src/slm/local_llama_transducer.py):
- Оборачивает вызовы `llama_cpp.Llama` с потокобезопасными блокировками исполнения.
- Управляет аппаратным переносом слоев на GPU (`n_gpu_layers = -1` для полного переноса в CUDA).
- Реализует «жадное» декодирование (`temperature = 0.0`, `repeat_penalty = 1.05`) с динамическим ограничением токенов для исключения галлюцинаций и зацикливаний.

### 2.3 Управление устройствами и ресурсами (`device_manager.py` и `resource_manager.py`)
- [`src/slm/device_manager.py`](../../src/slm/device_manager.py): Анализирует доступные аппаратные ресурсы (NVIDIA CUDA, ROCm, Apple Metal или потоки CPU).
- [`src/slm/resource_manager.py`](../../src/slm/resource_manager.py): Автоматически выделяет память под контекст и сбрасывает KV-кэш между сеансами генерации отчетов.

### 2.4 Модуль фактической сверки (`revision_engine.py` и `output_sanitizer.py`)
- [`src/slm/revision_engine.py`](../../src/slm/revision_engine.py): Извлекает числовые сущности из сгенерированного текста и сверяет их со строгими значениями из базы данных SQL.
- [`src/slm/output_sanitizer.py`](../../src/slm/output_sanitizer.py): Удаляет лишнюю разметку markdown, пробельные символы и артефакты повторов.

## 3. Настройка конфигурации и хранилище моделей (`Model_Vault/`)

Предобученные веса хранятся в локальном каталоге `Model_Vault/`:

```text
Model_Vault/
└── Qwen3.5-2B-UD-Q6_K_XL.gguf
```

Конфигурация в файле `config/settings.ini`:
```ini
[REPORT_FORMATTING]
report_slm_device = auto
report_slm_gpu_layers = -1
xai_slm_device = auto
xai_slm_gpu_layers = -1
```

Параметры инференса, настроенные в [`semantic_transducer.py`](../../src/slm/semantic_transducer.py):
- **Путь к модели:** `Model_Vault/Qwen3.5-2B-UD-Q6_K_XL.gguf`
- **Контекстное окно (`n_ctx`):** `8192`
- **Температура:** `0.0` (детерминированная / жадная выборка)
- **Штраф за повторы (repeat penalty):** `1.05`
- **Максимум выходных токенов:** Динамический расчет (`512` до `4096`)
