## 1. Нативный Go-шлюз (`bin/carina-go`)
Все сетевые протоколы дорожного оборудования (UDP 161 и 162) вынесены в скомпилированный бинарный файл на языке Go:
- **Безопасный IPC через Pipes:** Взаимодействие между Python и Go осуществляется исключительно через стандартные каналы ОС (`stdin`/`stdout`) с форматом строк NDJSON. Хост не открывает сетевых портов для управления.
- **Атомарный Fail-Safe:** При аварийном завершении процесса Python ядро ОС закрывает канал (`EOF`), что фиксируется за микросекунды — шлюз немедленно отправляет команду освобождения контроля по SNMP, возвращая перекресток в локальный жесткий план.

## 2. Поддерживаемые протоколы
- **NTCIP 1202:** Фиксация активной фазы (`ascPhaseHold`), принудительный сброс (`ascPhaseForceOff`), вызов фаз.
- **UTMC / UTMC2 (Великобритания):** Переключение и опрос ступеней (Stage 1..8).
- **Python Proxy (`GoTrafficDriverProxy`):** Прозрачный адаптер для ядра искусственного интеллекта.
