# 🗄️ База данных и схемы хранения

Документ описывает уровень реляционного хранения данных CARINA, асинхронную пакетную запись и схемы таблиц в PostgreSQL.

⬅️ [Главный Хаб](../README.md) | 🏛️ [Архитектура](architecture.md)

---

## 1. Асинхронное дельта-сжатие
Для предотвращения блокировки шага управления (< 1 мс) запись в БД выполняется фоновыми воркерами с группировкой по 50 записей. RLE-сжатие снижает дисковую нагрузку на **97.9%**.

---

## 2. Основные таблицы
- `step_decisions`: Решения агентов, вето безопасности и таймеры.
- `synapse_fluid_dynamics`: Телеметрия транспортных потоков по полосам.
- `hardware_controller_connections`: Параметры соединения со светофорными контроллерами.
- `users`: Пользователи системы с хэшированием паролей bcrypt.
