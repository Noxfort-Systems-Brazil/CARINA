# ⚡ Спецификация API Synapse HFT и каналы IPC

Документ содержит описание высокоскоростного интерфейса gRPC и каналов межпроцессного взаимодействия CARINA.

⬅️ [Главный Хаб](../README.md) | 🏛️ [Архитектура](architecture.md)

---

## 1. Служба Synapse HFT (`proto/synapse_hft.proto`)
- **Порт:** `50051`.
- **Методы:**
  - `Ping`: Проверка статуса с задержкой отклика $< 1\text{ мс}$.
  - `LoadScenario`: Передача топологии дорожной сети и геометрии.
  - `SystemControl`: Управление состоянием (`START`, `PAUSE`, `STOP`, `RESET`).
  - `StreamTraffic`: Непрерывный поток данных очередей, плотности и скоростей.

---

## 2. Каналы памяти IPC
Полная развязка задач через 10 буферизованных очередей (`controller_conn`, `ai_conn`, `wd`, `sds`, `sas`, `ui`, `ui_telemetry`, `db`, `g_state`, `g_signal`).
