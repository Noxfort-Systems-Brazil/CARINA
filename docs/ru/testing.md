## 1. Запуск тестовых сценариев
```bash
# Модульные тесты Python
./.venv/bin/pytest tests/ -v

# Отчет о покрытии кода
./.venv/bin/pytest tests/ -v --cov=src

# Тестирование Go-шлюза
cd src_go && go test -v ./...
```
